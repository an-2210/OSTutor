# OSTutorLLM Frontend Documentation

## Overview

The `frontend/` directory is reserved for the lightweight web user interface of **OSTutorLLM**. 

As per the Phase 8 development roadmap, the web frontend will provide an interactive interface for students to:
- Ask conceptual OS questions and receive RAG-augmented answers with source citations.
- Practice viva questions, numerical CPU scheduling/memory problems, and code debugging.
- Filter questions by OS Syllabus Unit (Units 1–7) and Bloom taxonomy level.

## Planned Technology Stack

- **Framework:** React + Vite / HTML5 + Vanilla JS
- **Styling:** CSS3 / Modern Glassmorphism & Responsive Layout
- **API Integration:** REST / Fetch calls to `backend/main.py`

## Current Status

*Frontend implementation is intentionally deferred until Phase 8 (after RAG and Fine-Tuned Model Integration in Phase 6).*
